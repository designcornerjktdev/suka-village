# Backend Suka Village: Rencana Implementasi

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Mengganti mock `localStorage` dengan backend sungguhan (Postgres, DOKU
Direct API, email, login admin, upload disk lokal) tanpa mengubah tampilan.

**Architecture:** Satu repo Next.js 16. Route Handlers di `app/api/**` adalah
lapisan tipis. Logika domain ada di `lib/server/**` dan memakai ulang
`lib/booking/{pricing,promo,occupancy,format,notifications,email}.ts`.
`lib/booking/api.ts` dan `hooks.ts` tetap menjadi satu-satunya titik yang
dipanggil komponen, dengan nama dan bentuk hasil yang sama.

**Tech Stack:** Next.js 16.3, React 19, TypeScript, Prisma + PostgreSQL 16
(Docker), zod, SWR, argon2, nodemailer, sharp, qrcode, vitest.

**Spec:** `docs/superpowers/specs/2026-11-17-backend-design.md`, plus
`docs/BOOKING.md` sebagai kontrak endpoint. Executor wajib membaca keduanya.

## Global Constraints

- Baca `node_modules/next/dist/docs/` sebelum memakai API Next yang belum
  dikenal. Middleware di versi ini bernama `proxy.ts`.
- Tanggal menginap: string `yyyy-mm-dd` (Asia/Jakarta), tipe `@db.Date`.
  Waktu kejadian: `DateTime` UTC. Uang: rupiah `Int`.
- **Portabel ke MySQL:** dilarang memakai partial index, tipe array (`String[]`),
  `$queryRaw` khusus Postgres, atau filter JSON khusus `jsonb`.
- Bentuk data yang keluar dari API = tipe di `lib/booking/types.ts`, tanpa
  perubahan.
- Harga, diskon, dan ketersediaan **selalu dihitung ulang di server**.
- Email dikirim **setelah** transaksi commit. Kegagalan email tidak
  membatalkan operasi.
- Tidak ada perubahan tampilan di komponen UI.
- Teks yang terlihat pengguna: tanpa em dash.
- Env: `DATABASE_URL`, `SESSION_SECRET`, `CRON_SECRET`, `DOKU_CLIENT_ID`,
  `DOKU_SECRET_KEY`, `DOKU_ENV` (`sandbox`|`production`), `SMTP_URL`,
  `MAIL_FROM`, `UPLOAD_DIR`, `SITE_URL`.

## Review Focus

1. **Dua tamu menekan Bayar untuk malam yang sama dalam detik yang sama.**
   Tepat satu yang berhasil, yang lain mendapat `unavailable`. (Task 3,
   `concurrent create`)
2. **Webhook DOKU datang dua kali, atau datang setelah booking kedaluwarsa.**
   Status tidak berubah dua kali dan email tidak terkirim dua kali. Paid
   setelah expired dicatat untuk refund, tanpa membangkitkan booking. (Task 7)
3. **Promo berkuota 1 dipakai dua booking bersamaan.** Hanya satu yang
   mendapat diskon. (Task 3, `promo quota race`)
4. **Hold lewat waktu tapi cron belum jalan.** Malamnya terlihat kosong dan
   bisa dipesan tamu lain. (Task 3, `lapsed hold frees nights`)
5. **Kode booking ditebak tanpa token.** Hasilnya 404, sama seperti kode yang
   tidak ada. (Task 5)
